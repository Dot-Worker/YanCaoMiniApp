# 原生微信小程序 · 本地资料预览

这是 **WXML / WXSS / JavaScript 原生小程序源码**，不是网站、HTML 壳或 Sites 项目。当前交付范围仅为本地预览；未上传微信、未发布体验版/正式版，也未宣称全站采集完成。

## 已实现

- **资料首页**：真实快照统计、搜索入口、已有详情品牌、来源边界与健康提示。
- **品牌目录**：522 个已见品牌，默认只看已有详情的 2 个品牌，可切换全部；中文/英文名称搜索、分批显示。没有猜测品牌产地、类别或英文译名。
- **产品列表**：82 条冻结详情，按明确目录关系分为中华 56 条、黄鹤楼 26 条；可查名称、品牌与已转录条码。空结果不等于产品不存在。按来源名称排序，非推荐或热度排名。
- **实际图片与读数**：已纳入产品610的9个审核原图文件（共22,656 B）、6项规格数字、2个小盒条码与1个条装条码；其他81产品维持缺图/未转录状态。
- **来源详情**：实际本地图片或明确缺失状态、基础文字规格、数值/条码逐项状态、来源页面与完整采集时间；多个小盒条码并列保留。
- **本地收藏 / 搜索历史**：仅微信本地存储，收藏去重，历史最多 6 条。写入失败不显示虚假保存成功。可清除搜索历史、取消收藏。
- **来源说明**：区分来源文本、人工读图、待核验与未采集；不把来源值当作实测或厂家认证。

不包含购买入口、价格/比价/销量排名、吸烟或口味推荐、促销文案、宣传性原文介绍、模拟识图、AI 包装图、用户账号、年龄/手机/位置采集、云端后端、外部模型、付费接口、分析统计、网络同步或远程图片请求。

## 导入方式（尚待开发者工具验证）

1. 将仓库源码保存到本机；使用微信开发者工具的 **小程序项目导入**，选择仓库内的 **`WeChatAPP/` 目录**（该目录包含 `project.config.json`），不要选择仓库根目录。
2. 项目配置的 `miniprogramRoot` 指向 `miniprogram/`，编译类型为 `miniprogram`。没有 npm 依赖，不需要构建 npm。
3. `appid: "touristappid"` 是明确的本地测试占位，不是真实 AppID。若当前工具不接受该占位，应在导入界面选择其支持的测试方式；本次没有替你注册、授权、登录或申请 AppID。正式 AppID 必须由项目拥有者另行提供。
4. 不固定猜测的 `libVersion`，由工具选择可用基础库；URL 校验保持开启。数据/图片随源码打包，不需要配置服务器域名。
5. 导入后检查编译错误与首页。先完成下面的模拟器清单，再安排真机验证；**不要点击上传或发布**，本任务没有授权发布微信版本。

本次执行环境没有微信开发者工具、微信运行时或连接真机。已运行的是 Node 单元测试、页面逻辑 mock 测试和离线结构校验，**不是微信编译通过证明**。AppID 占位的工具兼容性也尚未实际验证。

## 设计与数据边界

- 米白 `#F6F5F0` 背景、石墨/深绿文字、克制的绿色点缀；普通按钮最小触控高度 44 px。保留系统导航和三个原生底部导航项。
- 不采用金色奢华、品牌促销海报、吸烟场景或排名。首页以资料收录状态而非产品营销图为主。
- 不使用进度百分比：333 是当前已见品牌—产品索引关系，251 是其中尚无详情的关系，不是全站待办总量。其余 520 个品牌产品总量未知。
- 82 表示已审离线快照的数量，**不表示 82 个产品全部规格核验完成**。未知数字保留 `null`；0 与缺失严格区分。
- 目录品牌归属由实际来源列表证据关联；英文产品 `Chunghwa (Thailand)` 也按明确目录关系归属中华，不靠名称包含“中华”推断。
- 实际图像是否纳入及数量以 `miniprogram/data/provenance.json` 和 `asset-manifest.json` 为准。只有产品 610 获单独逐图核验后才可纳入 9 个原字节文件（1 WebP 主图 + 8 PNG 数值/条码图），6 项读数和 3 条条码；其他 81 产品不因复用同一图片 URL 而自动获得数值或图片。
- 610 的两个小盒条码均保留，不确定主版本；20 支和 10 盒的单位由字段语境提供，不声称图片印有单位。
- 图片保留原字节及来源水印，不裁切、不重绘、不重编码。WebP 在目标工具/真机上的实际显示尚待验证；加载失败显示“本地原图暂无法显示”，不会转向远程下载或偷偷转换格式。
- 来源记录为用户贡献百科，不是厂家认证、实验测量、真伪鉴定或实时生产/销售状态。低焦油不代表低危害。
- 逐值公开证据仅保留来源URL、图像/快照hash、目标字段、单位依据、时间及完整审核对象的规范摘要；内部完整审阅记录不随客户端公开。
- 原文宣传性介绍未核验，暂不展示。第三方图片和文字的使用基于项目发起方声明的授权；不是向下游开放授权，源码许可不覆盖第三方内容。

## 本地检查

只需要 Python 3 和支持 `node:test` 的 Node（本次运行版本见 QA 报告），无新增第三方依赖。下列命令在仓库内 `WeChatAPP/` 目录执行（从仓库根先运行 `cd WeChatAPP`）。

```sh
node --test preview-tests/*.test.js
PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -s preview-tests -p 'test_*.py' -v
python preview-tests/validate_static.py
```

- 单元：中文/英文搜索、大小写/空结果/清空、目录关系、0/null、多个条码、缺图、本地收藏去重与异常、历史去重/上限/清除、分页。
- 页面 mock：搜索→详情→返回的上下文保持、重复点击、导航失败/重试、无历史直接进入的返回、安全空状态、收藏标签刷新/失败、图片加载失败及证据展开/收起。
- 静态：6 页注册、7 个 WXML 文件的结构和组件/event 引用、JS/JSON 语法、所有 data/asset 引用、实际 asset SHA/字节长度、远程资源和账号/网络 API 禁用、公开数据无私有路径/凭据/价格宣传字段。

这些检查不代替 WXML 编译器、样式渲染、可访问性测试、真实微信导航/存储行为或平台审核。没有把 HTML 仿制截图当作微信真机证据。

## 目录与维护

以下路径均相对于 `WeChatAPP/` 项目根。采集器仍在仓库原目录，与此客户端分开；仓库根不放小程序项目配置。

- `miniprogram/`：全部客户端源码、冻结中立数据与已审核实际图片；运行时只读。
- `preview-tools/build_data.py`：离线白名单导出器；输入 SHA 固定，只接受本轮已审数据。**不自动读取采集中目录**，不修改原采集器或数据库。
- `preview-tests/`：单元、页面 mock 和静态检查。
- `preview-tools/README.md`：数据更新/复现合同。
- `docs/PREVIEW_QA.md`：验证边界、已测/未测清单。

新增采集结果需要单独结束批次、审核并更新导出合同；不要将工作中 SQLite 直接替换进客户端，也不要将“导入成功”标记为“全字段核验完成”。
