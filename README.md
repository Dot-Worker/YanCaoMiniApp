# YanCaoMiniApp

烟草百科微信小程序项目，定位为中立资料检索工具，不提供烟草销售、购买引导或促销功能。**先采集并校验资料，再实现小程序界面。**

## 当前阶段

- 已加入 **原生微信小程序本地预览源码**（WXML / WXSS / JavaScript）：首页、品牌目录、产品列表/搜索、详情、收藏与搜索历史。导入说明见 [WeChatAPP/PREVIEW_README.md](WeChatAPP/PREVIEW_README.md)。
- 本轮冻结展示数据为 **82 条详情、522 个已见品牌**，由明确目录证据关联中华56条、黄鹤楼26条；不是全站数据库。333条已见索引关系中251条尚无详情，其余品牌产品总量未知。
- 产品610包含 **9张已授权原字节图片、6项人工读图规格和3条条码**；两条小盒条码并列保留，不猜主版本。其余81条保持未核验数值/缺图状态；图片复用不等于数值已核验。
- 本仓库只提供批准的有限客户端静态投影、9图、源码和有限脱敏/合成夹具；不公开运行SQLite、整批原字段快照、下载元记录、完整内部审核记录或会话。
- **未运行微信开发者工具编译、模拟器或真机；未上传体验版/正式版，未通过平台审核。** Node/mock/结构检查不等于微信运行验证。
- 原 Actions 来源试跑仍因 HTTP403 暂停：2次请求、73字节、0成功页面/产品/图片；本轮不重跑、不解除暂停、不增加来源请求。正常浏览器观察与离线导入的结果不能证明该路径已恢复。
- 资料来自用户贡献百科，不是厂家认证、实测、真伪或实时生产状态；未知字段保留 `null`，不提供销售、价格、购买引导或推广。

## 目录

- `WeChatAPP/`：可直接导入的原生微信小程序项目根；内含 `project.config.json`、`miniprogram/`、经审中立静态数据与9张本地原图。
- `WeChatAPP/preview-tools/`、`WeChatAPP/preview-tests/`：白名单导出与客户端离线验证。
- `tools/yanyue/`：目录、详情解析与受限浏览器采集、断点和 JSON 检查点。
- `tools/offline_batch/`：仅处理已结束本地快照批次的串行离线包装器，复用同一适配器与存储。
- `tools/tests/`：离线测试及必要的源站页面片段/合成夹具。
- `data/*.schema.json`：产品和检查点数据合同。
- `.github/workflows/data-pipeline.yml`：提交/PR 离线测试，以及显式手动触发的微型试跑。

微信开发者工具导入时选择 **`WeChatAPP/` 文件夹**，不是仓库根目录；采集器和数据合同继续放在根 `tools/`、`data/`，两者分开。

## 离线检查

使用 Python 3.12 和支持 `node:test` 的 Node.js；Node 缺失会明确失败，不跳过客户端检查：

```sh
python -m pip install -r tools/requirements-test.txt
PYTHONPATH=tools python -m unittest discover -s tools/tests -v
PYTHONPATH=tools python -m yanyue.cli crawl --state-dir data/runtime
```

最后一条只输出计划；**不带 `--execute` 不访问来源站**。完整说明、字段限制及断点恢复方法见 [`tools/README.md`](tools/README.md)。

公开图像证据可自包含只读复验，见 [PUBLIC_IMAGE_VERIFICATION.md](PUBLIC_IMAGE_VERIFICATION.md)。它验证固定已审值、字段关联和本地原图字节，不是新OCR、下载、写库或私有bundle恢复。

## 受限试跑与完成标准

自动 CI 不抓取来源站。手动工作流首次最多发出 5 次来源请求（包括 robots、加载导航等）、最多 5 页、0 张图片、10 MiB、180 秒，且单工作者请求间隔至少 5 秒。成功页数可能少于页数上限。来源阻断、异常和中断停止运行，不自动重试或绕过访问控制。

Actions 原检查点仍只保存经过验证的 JSON，不上传 SQLite、浏览器档案、Cookie、原始网络日志或图片二进制。另有仅供本地受控资料保存的图像证据 bundle，不会自动上传；完整图片采集仍未完成。客户端9图是已单独批准的静态展示文件，不是 Actions 新采集结果。

单次任务成功不代表全站采集完成。覆盖率报告区分已发现、已解析、待处理、失败和暂停；数值图、原文内容区及图片集仍需按实际解析与核验结果逐步完成，未知值不猜测。完整采集、数据审查和平台合规确认后，再进入小程序交付阶段。

## 已验证的试跑状态

2026-10-26 的[首次受限试跑](https://github.com/Dot-Worker/YanCaoMiniApp/actions/runs/40381732787)已停止。随后仅从现有检查点执行了[离线诊断](https://github.com/Dot-Worker/YanCaoMiniApp/actions/runs/40385402374)，验证到 `paused=true`、`stop_reason=source_http_403`；未重新访问来源站。

HTTP 403 本身不能证明是机器人验证，也不能证明网站对所有访问者都不可用。该 Actions 来源路径当前不重试、不恢复采集、不清除暂停，也不更换访问身份或网络路径来规避限制。恢复该路径前，需要官方数据导出、授权 API 或网站认可的访问方式。

兼容性修复只针对已保存页面片段与合成夹具中的正常 HTTP 200 页面流程。后续快照导入只读取已保存的本地字段 JSON，不访问网络、不启动原 Actions 采集、不清除暂停。离线测试及单品牌导入通过均不代表 HTTP 403 已解决，也不代表全站数据、完整图片或小程序已交付。具体范围见 [浏览器快照离线导入说明](BROWSER_SNAPSHOT_IMPORT.md)。
